# Changelog

Notable changes to the STM32WB55 OTA Updater are documented here.

## U0.1.0

- Added BLE scanning, device connection, device information, and connection diagnostics.
- Added firmware file selection and BLE OTA transfer with erase and upload progress, batch sizing options, speed, and ETA.
- Added transfer logging, retry handling, and connection-loss reporting.
- Added the updater app version to the Bluetooth screen.
